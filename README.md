A coverage path planning (CPP) algorithm, or an algorithm that can determine a path that passes over every point in the space, are relevant in cases such as vacuum cleaning or lawn mowing, where a path that covers the whole area needs to be found. For situations like sweeping or snow shoveling, however, it is not enough to just find a path that covers an area but also has a designated start and end position. 

The main objective of this project is to implement a CPP algorithm that can produce a path with a desired start and goal position. The situation this algorithm is going to be used for is for shoveling snow. Thus, the algorithm was designed such that a robot with a shovel at the front of its body can start at any position in an area filled uniformly with snow and shovel all snow into a designated goal position.
